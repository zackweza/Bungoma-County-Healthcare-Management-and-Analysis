# Bungoma County Healthcare Management and Analysis

## Project Overview
This project focuses on analyzing healthcare data to understand health care facilities, services, and other other factors that can support better healthcare management and decision- making in Bungoma County, Kenya.
The project follows an end-to-end data analysis process, from data preparation and cleaning to analysis, visualization, and reporting.

## Objectives
-Clean and prepare healthcare data  for analysis.
-Analyze healthcare facilities and available services.
-Identify important patterns and trends in the data.
-Create visualizations to communicate findings clearly.
-Generate insights that can support healthcare planning and decision-making.

## Tools Used

- python
- SQL
- Power BI
- Github

  ## Project Components
- `capstsone.Py` -python analysis and data processing code.
- `healthcare.db` -SQLite database used for SQL analysis.
- `bungoma_clean.csv` - cleaned dataset.
- `Charts/` - Project visualization created by matplotlib
- `Power BI/`- Power BI dashboard/report files.
